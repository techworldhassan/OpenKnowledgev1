# OpenKnowledge

OpenKnowledge is a static GitHub Pages encyclopedia reader. It searches and
loads Wikipedia article content through the public MediaWiki API, then presents
the result in a distinct OpenKnowledge interface.

## Hosting on GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to **Pages**.
4. Set the source to the default branch and root folder.
5. Save, then open the published Pages URL.
